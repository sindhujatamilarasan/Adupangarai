# Adupangarai: Android app (React Native + Expo)

The native Android app is written in **React Native + TypeScript** with **Expo**. It talks to the same Laravel API as the website, so all business rules stay on the server.

```
mobile/
  src/app/           screens (Expo Router: every file is a screen; (tabs)/ is the bottom bar)
  src/components/    UI pieces (Text, Card, Button, Field, Kolam, Logo, TopBar…)
  src/lib/           api.ts (fetch + token), auth.tsx, i18n.tsx, storage.ts
  plugins/           Android build settings (signing, R8, phone CPUs), applied on every prebuild
../shared/           code used by both the website and this app: Tamil text (ta.ts), API types, kolam maths, logo
```

## Run on a phone while developing
1. Install a test build once (below). The Expo Go app can't be used, because the app has native modules such as Google sign-in.
2. Start the dev server: `EXPO_PUBLIC_API_URL=http://<your PC's LAN IP>:8787 npx expo start`.

## Build (Docker, no Android Studio)
```bash
docker build -f docker/android-build.Dockerfile -t adupangarai-android docker        # once
docker build -f docker/mobile-build.Dockerfile -t adupangarai-mobile-build docker     # once
cd mobile
EXPO_PUBLIC_API_URL=https://your-api npm run android:apk   # test APK
EXPO_PUBLIC_API_URL=https://your-api npm run android:aab   # Play Store bundle
```

**Test APK:**
- Signed with the debug key from `../keys/debug.keystore`, the key Google sign-in is registered with.
- Output: `android/app/build/outputs/apk/release/app-release.apk`.

**Play Store bundle:**
- Signed with the upload key from `../keys/keystore.properties`.
- Output: `android/app/build/outputs/bundle/release/app-release.aab`.
- Raise `android.versionCode` in `app.json` for every upload.

**Keys:**
- `../keys/` is gitignored, so back it up.
- `android/` is generated by `expo prebuild`; never edit it by hand. Change `app.json` or `plugins/` instead.

## Checks
```bash
npx tsc --noEmit && npx expo lint && npm test   # npm test fails if any text has no Tamil translation
```
